Projects home page

The main homepage of the varioius projects I've worked on over the years. None of these currently have usable links as all are being overhauled.

Character Database

A web-based front end built in HTML and CSS, without a framework. The backend was built in PHP, with a regular front-end.

Modpack installer

A Java-based program for a now defunct modded Minecraft server. It would download the mods, and install it for you with minimal input.

Character Generator

A simple character generator made in Java meant to be locally ran.

Character Weight System

(Still in progress) A system designed to accurately estimate the weight of a fictional anthro character using real world science.

Physbone-QC converter.

A Java based program to read an avatar's Unity scene file, extract the physbones, and convert them to JiggleBones for usage in the source game engine.
